## v2 (after Fable 5.1 review) — current version
**Audio:** `short-01-dime-v2-darren.mp3` (~71 s) · **Script:** `narration-v2.txt` (v1 kept as `narration-v1.txt` / `short-01-dime-darren.mp3`)

Changes:
- **Logic fix:** the size wasn't simply "cheap metal, so bigger." Cheap metal freed the size from value, and Congress set it. A House committee raised the weight, officially to make an even 5 grams. ([Wikipedia: Shield nickel](https://en.wikipedia.org/wiki/Shield_nickel))
- **Dropped** "worth their weight in metal." It's only roughly true after the 1853 Coinage Act.
- **The goblin line now uses "goblin" both times,** so the payoff is a return, not a new word. Etymonline glosses *Kupfernickel* as "copper goblin."
- **New lines:** "Blame a Civil War panic…" replaces "The answer runs through…". "The big coin is the cheap one" is the cleaner landing.
- **"Wharton made millions on nickel"** is sourced: he had made several million in profit from nickel by the 1870s.
- **Trimmed** to about 181 words.
- **TTS fix:** "a round five grams" sounded like "around five grams," so it's back to "an even five grams." A transcript of the audio matches the script exactly.

Fable's note on the tease: the ridges answer alone is thin, so the next Short should use the stronger far end (the 1690s coin-clipping crisis → the Great Recoinage → the window tax).
